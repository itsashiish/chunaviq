# Security invariants and where they are tested

Each invariant is enforced at runtime **and** re-checked from the public record by the independent verifiers (Python and TypeScript). The test column names the functions that would fail if the invariant broke.

| # | Invariant | Enforced by | Verifier check | Tests |
|---|---|---|---|---|
| I1 | No ballot is accepted outside the authorised period | `BallotBox._gate` (state + clock, re-checked inside the lock) | `record.structure`, `ballots.window`, `lifecycle.open_time` | `test_no_ballot_before_open`, `test_window_enforced_even_if_officer_never_closes`, `test_no_ballot_after_close`, `test_cannot_open_before_published_time`, `test_ballot_injected_after_close`, `test_finalization_refused_while_open` |
| I2 | Each voter has at most one valid tag, and at most one counted ballot | one registration row per voter (IMMEDIATE txn); re-registration and polling-day override revoke the old tag; finalization flags only the last ballot of a valid tag | `registration.summary`, `finalization.proofs`, `mixing.counted_tags` (counted tags distinct and valid) | `test_concurrent_registrations_of_one_voter_keep_one_valid_tag`, `test_reregistration_limit`, `test_in_person_voter_cannot_register_again`, `test_aadhaar_and_pan_resolve_to_one_roll_entry`, `test_ballot_box_counts_two_ballots_of_one_voter`, `test_ballot_box_counts_a_revoked_tag`, `test_concurrent_revotes_are_all_recorded_and_numbered` |
| I3 | Only eligible, authenticated voters register; ballots need a registered tag and a proof of its secret | roll lookup, identity method, lockout, session-bound Schnorr proof; registered-tag check, tag proof, private link proof | `ballots.valid`, `registration.summary`, `mixing.counted_tags` | `test_each_identity_method_registers`, `test_unknown_aadhaar`, `test_aadhaar_holder_not_on_this_roll`, `test_wrong_otp_and_lockout`, `test_impostor_face_rejected`, `test_pan_alone_is_not_enough`, `test_registration_proof_bound_to_session`, `test_tag_cannot_be_reused`, `test_unregistered_tag_rejected`, `test_wrong_tag_link_rejected`, `test_insider_stuffs_a_ballot_without_tag_proof` |
| I4 | Invalid or modified ballots cannot become valid votes | `check_ballot` (schema, subgroup, proofs) | `ballots.valid`, `ballots.tracking_codes` | `test_overvote_rejected`, `test_blank_ballot_rejected`, `test_ciphertext_outside_subgroup_rejected`, `test_marked_ballot_rejected`, `test_fuzzed_ballots_never_crash_and_never_accepted`, `test_insider_alters_ballot_and_resigns`, `test_tag_proof_rejects_any_tampered_field` |
| I5 | Ballots cannot be copied under another tag | every proof bound to the tag ciphertext; tag proof bound to the ballot body; α uniqueness | `ballots.no_copies`, `ballots.valid` | `test_ballot_copying_into_own_ballot_rejected`, `test_tag_proof_complete_sound_and_bound`, `test_disjunctive_bound_to_context_key_and_ciphertext`, `test_insider_duplicates_a_ballot` |
| I6 | The record cannot be silently altered, truncated, reordered or forked | append-only board, signed checkpoints, consistency proofs | `record.canonical`, `board.checkpoints`, `board.sealed` | `test_outsider_alters_a_ballot`, `test_outsider_deletes_a_ballot`, `test_outsider_truncates_record`, `test_outsider_forks_checkpoint_history`, `test_board_refuses_truncated_history`, `test_board_refuses_forged_checkpoint`, `test_insider_drops_a_ballot_and_resigns` |
| I7 | Published totals equal an independently reproducible tally of the last ballot per valid voter | finalization OR-proofs; verified shuffles; CP-proven decryption shares | `finalization.*`, `mixing.shuffles`, `mixing.counted_tags`, `tally.*` | `test_finalization_cannot_count_a_ballot_with_flag_zero`, `test_finalization_cannot_change_the_vote`, `test_shuffle_soundness`, `test_mixer_replaces_a_row`, `test_insider_flips_finalization_after_mixing`, `test_insider_with_officer_key_changes_result`, `test_insider_with_officer_key_swaps_winner_flag`, `test_tampered_decryption_share`, `test_simulation_record_verifies_and_matches_ground_truth` |
| I8 | No single party can decrypt; individual votes are never decrypted | k-of-n threshold key in HSMs; trustees decrypt only totals, mixed flags and mixed counted tags | `ceremony.*`, `tally.decryption` | `test_fewer_than_k_cannot_decrypt`, `test_no_trustee_holds_the_joint_secret`, `test_trustees_never_decrypt_an_individual_vote`, `test_share_never_leaves_in_plaintext`, `test_policy_refusals` |
| I9 | Audit records reveal no identities, and do not link a voter's ballots to each other or to the count | encrypted tags, private link proofs, mixing, hour buckets, sorted lists, identity-free logs | (structural) | `test_public_record_contains_no_voter_identifiers`, `test_public_record_does_not_link_revotes`, `test_ballot_box_database_holds_no_identity`, `test_eligibility_database_stores_no_raw_identity_numbers`, `test_eligibility_database_never_sees_ballots`, `test_logs_carry_no_identity`, `test_record_timestamps_are_hour_granular`, `test_registration_lists_are_sorted_not_in_registration_order` |
| I10 | An election cannot be declared verified if evidence is missing or a check fails | verifiers treat every missing item as FAIL | all | `test_missing_publication_step`, `test_missing_checkpoints_file_fails`, `test_manifest_swapped_after_open`, `test_insecure_group_refused_unless_flagged`, `test_wrong_pinned_manifest_hash`, `test_source_digest_pin` |
| I11 | The election survives crashes, DB loss and an unavailable trustee without double-counting | board-authoritative recovery; reconcile check; quorum check before any publication | `board.sealed`, `finalization.complete` | `test_board_reload_reproduces_state_and_root`, `test_reconcile_detects_board_index_divergence`, `test_tally_fails_safely_without_quorum`, `test_tally_succeeds_with_exactly_threshold_trustees`, `test_tally_survives_unavailable_trustee`, `test_backup_restore_verifies_identically` |
| I12 | The verifier is independent of the code it checks | separate package, no `chunaviq` imports, own group constants | — | `test_verifier_shares_no_code_with_election_package`, `test_groups_rederive_from_public_seed_independently`, `test_shuffle_generators_match_and_are_independent_of_g` |
| I13 | A national result is accepted only if every shard verifies, is bound to the national election and uses the one national key | signed national manifest, ceremony and shard index | `national.*`, `shards.verified`, `shards.bound` | `test_federation_verifies_and_matches_ground_truth`, `test_federation_missing_shard_fails`, `test_federation_swapped_shards_fail`, `test_federation_uses_one_national_key`, `test_federation_shard_with_its_own_key_fails`, `test_federation_altered_national_result_fails` |
| I14 | Sequencer and verifier memory do not grow with record size | streaming board, finalization, mixing and verifier; on-disk indexes | — | `test_verifier_memory_does_not_grow_with_record_size`, `test_board_keeps_bodies_on_disk` |
| I15 | A retried identical ballot gets its original receipt and is never recorded twice; the same ballot under another tag is refused | tag-aware idempotent ballot box (also in the batch race path) | `ballots.no_copies` | `test_identical_retry_returns_original_receipt`, `test_concurrent_duplicate_ballot_submissions_record_exactly_one`, `test_group_commit_enforces_uniqueness_and_revote_limits`, `test_identical_ballot_racing_in_one_batch_is_idempotent_only_under_its_own_tag` |
| I16 | Counting works at the largest constituency size | baby-step giant-step | `tally.results` | `test_count_recovery_at_constituency_scale_both_implementations`, `test_threshold_tally_of_a_58_lakh_vote_total` |
| I17 | A coercer cannot tell whether a watched ballot counted | revoting; encrypted flags; designated-verifier proof the voter can fake; revocations hidden while voting | (by construction) | `test_coercion_scenarios`, `test_designated_verifier_proof_convinces_only_the_voter`, `test_revoked_tag_is_still_accepted_while_voting` |
| I18 | Trustee shares are used only inside HSMs, after close, with operator and observer quorums, and every use is logged | `custody.TrusteeApplet` policy | `hsm logs` (published, chained, signed) | `test_ceremony_in_hsms_gives_one_share_each_and_decrypts_totals`, `test_policy_refusals`, `test_observer_refuses_when_its_check_fails`, `test_audit_log_is_chained_signed_and_published`, `test_seal_unseal_and_clone_to_backup_hsm`, `test_feldman_check_inside_hsm_rejects_bad_share`, `test_hsm_logs_published_and_verified` |
| I19 | Abuse is refused before it costs proof work, and honest ballots still get through under attack | rate limits, load shedding, schema, registered-tag and per-tag checks before proofs; HTTP limits | — | `test_token_bucket`, `test_http_limits`, `test_connection_cap`, `test_smoke_dress_rehearsal`, `test_sequencer_ingest_beats_largest_constituency_need` |
