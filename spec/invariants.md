# Security invariants and where they are tested

Each invariant is enforced at runtime **and** re-checked from the public record by the independent verifier. The test column names the pytest functions that would fail if the invariant broke.

| # | Invariant | Enforced by | Verifier check | Tests |
|---|---|---|---|---|
| I1 | No ballot is accepted outside the authorised period | `BallotBox._gate` (state + clock, re-checked inside the lock) | `record.structure` (ballots only between OPEN and CLOSED), `ballots.window`, `lifecycle.open_time` | `test_no_ballot_before_open`, `test_window_enforced_even_if_officer_never_closes`, `test_no_ballot_after_close`, `test_cannot_open_before_published_time`, `test_ballot_injected_after_close` |
| I2 | No voter exceeds one counted ballot, even under concurrency | issuance PK + IMMEDIATE txn; token PK + lock | `ballots.one_per_credential`, `reconciliation.participation` | `test_one_credential_per_voter`, `test_concurrent_credential_requests_issue_exactly_one`, `test_concurrent_duplicate_ballot_submissions_record_exactly_one`, `test_concurrent_different_ballots_same_credential`, `test_insider_duplicates_a_ballot` |
| I3 | Only eligible voters obtain credentials; ballots need a valid credential | roll lookup, auth, revocation, lockout; RSA-FDH verification | `credentials.issuer_keys`, `ballots.valid` | `test_not_on_roll`, `test_wrong_secret_and_lockout`, `test_revoked_voter_cannot_obtain_credential`, `test_insider_stuffs_a_ballot_without_credential`, `test_ballot_for_other_constituency_rejected` |
| I4 | Invalid or modified ballots cannot become valid votes | `check_ballot` (schema, subgroup, proofs) | `ballots.valid`, `ballots.tracking_codes` | `test_overvote_rejected`, `test_blank_ballot_rejected`, `test_ciphertext_outside_subgroup_rejected`, `test_marked_ballot_rejected`, `test_fuzzed_ballots_never_crash_and_never_accepted`, `test_insider_alters_ballot_and_resigns` |
| I5 | Ballots cannot be copied under another credential | proofs bound to token; α uniqueness | `ballots.no_copies` | `test_ballot_copying_with_own_credential_rejected`, `test_disjunctive_bound_to_context_key_and_ciphertext` |
| I6 | The record cannot be silently altered, truncated, reordered or forked | append-only board, signed checkpoints, consistency proofs | `record.canonical`, `board.checkpoints`, `board.sealed` | `test_outsider_alters_a_ballot`, `test_outsider_deletes_a_ballot`, `test_outsider_truncates_record`, `test_outsider_forks_checkpoint_history`, `test_board_refuses_truncated_history`, `test_board_refuses_forged_checkpoint` |
| I7 | Published totals equal an independently reproducible tally | homomorphic aggregation, CP-proven shares | `tally.aggregates`, `tally.decryption`, `tally.results` | `test_insider_with_officer_key_changes_result`, `test_insider_with_officer_key_swaps_winner_flag`, `test_tampered_decryption_share`, `test_simulation_record_verifies_and_matches_ground_truth` |
| I8 | No single party can decrypt; individual ballots are never decrypted | k-of-n threshold key; tally only touches aggregates | `ceremony.*`, `tally.decryption` | `test_fewer_than_k_cannot_decrypt`, `test_no_trustee_holds_the_joint_secret`, `test_trustees_decrypt_only_aggregates` |
| I9 | Audit records do not reveal individual selections or identities | data minimisation, hour buckets, sorted commitments, identity-free logs | (structural) | `test_public_record_contains_no_voter_identifiers`, `test_ballot_box_database_holds_no_identity`, `test_eligibility_database_never_sees_tokens_signatures_or_ballots`, `test_logs_carry_no_identity`, `test_record_timestamps_are_hour_granular`, `test_participation_commitments_are_not_in_issuance_order` |
| I10 | An election cannot be declared verified if evidence is missing or a check fails | verifier treats every missing item as FAIL | all | `test_missing_publication_step`, `test_missing_checkpoints_file_fails`, `test_manifest_swapped_after_open`, `test_insecure_group_refused_unless_flagged`, `test_wrong_pinned_manifest_hash`, `test_source_digest_pin` |
| I11 | The election survives crashes, DB loss and an unavailable trustee without double-counting | board-authoritative recovery; quorum check before any publication | `board.sealed`, `reconciliation.participation` | `test_board_reload_reproduces_state_and_root`, `test_index_rebuilt_after_database_loss_still_blocks_reuse`, `test_crash_between_board_append_and_index_commit`, `test_tally_fails_safely_without_quorum`, `test_tally_succeeds_with_exactly_threshold_trustees`, `test_backup_restore_verifies_identically` |
| I13 | A national result is accepted only if every constituency shard verifies and is bound to the national election | signed national manifest and shard index | `national.*`, `shards.verified`, `shards.bound` | `test_federation_verifies_and_matches_ground_truth`, `test_federation_missing_shard_fails`, `test_federation_swapped_shards_fail`, `test_federation_altered_national_result_fails` |
| I14 | Sequencer and verifier memory do not grow with record size | streaming board, tally and verifier; on-disk duplicate index | — | `test_verifier_memory_does_not_grow_with_record_size`, `test_board_keeps_bodies_on_disk` |
| I15 | A retried identical ballot gets its original receipt and is never recorded twice | idempotent ballot box | `ballots.one_per_credential` | `test_identical_retry_returns_original_receipt`, `test_concurrent_duplicate_ballot_submissions_record_exactly_one` |
| I16 | Counting works at the largest constituency size | baby-step giant-step | `tally.results` | `test_count_recovery_at_constituency_scale_both_implementations`, `test_threshold_tally_of_a_58_lakh_vote_total` |
| I12 | The verifier is independent of the code it checks | separate package, no `chunaviq` imports, own group constants | — | `test_verifier_shares_no_code_with_election_package`, `test_groups_rederive_from_public_seed_independently` |
