# National-scale capacity model (protocol v2)

Generated by `chunaviq capacity`. Unit costs are **measured** on the machine below; the national figures are **modelled** from them with the assumptions listed. Nothing here was run at 100-crore scale.

## Measured unit costs

Machine: 16 cores, Python 3.14.4, arithmetic backend `gmpy2`, 2048-bit group.

| Operation | Measured |
|---|---|
| Voter device: encrypt + prove a 4-option ballot, with tag proof and link (one core) | 12 ms |
| Server: verify a 4-option ballot and its tag link (one core) | 20 ms |
| Ballot box: finalize a 4-option ballot (flag, masked vote, OR-proof) | 12 ms |
| Verify that finalization | 15 ms |
| Record size of a 4-option ballot / its finalization | 16.1 KiB / 6.0 KiB |
| Voter device: encrypt + prove a 16-option ballot, with tag proof and link (one core) | 37 ms |
| Server: verify a 16-option ballot and its tag link (one core) | 59 ms |
| Ballot box: finalize a 16-option ballot (flag, masked vote, OR-proof) | 40 ms |
| Verify that finalization | 51 ms |
| Record size of a 16-option ballot / its finalization | 56.6 KiB / 19.8 KiB |
| One mixer: shuffle + prove, per (tag, flag) row | 3.5 ms |
| Verify one shuffle, per row | 5.0 ms |
| Shuffle output + proof, per row | 3.2 KiB |
| Derive one independent shuffle generator (once per batch position, cached) | 13.3 ms |
| One trustee's decryption share with proof | 1.0 ms |
| Verify a decryption share | 1.8 ms |
| Verify a registration (tag proof) | 0.8 ms |
| Recover a count of up to 60 lakh (baby-step giant-step) | 36 ms |
| Merkle append, per entry | 6 µs |
| Sequencer ingest, one shard, group commit with fsync | 2,614 ballots/s |
