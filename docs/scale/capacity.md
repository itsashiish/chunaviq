# National-scale capacity model

Generated by `chunaviq capacity`. Unit costs are **measured** on the machine below; the national figures are **modelled** from them with the assumptions listed. Nothing here was run at 100-crore scale.

## Measured unit costs

Machine: 2 cores, Python 3.13.16, arithmetic backend `gmpy2`, 2048-bit group, RSA-3072 credentials.

| Operation | Measured |
|---|---|
| Encrypt + prove a 4-option ballot (voter device, one core) | 17 ms |
| Verify a 4-option ballot (server, one core) | 27 ms |
| Record size of a 4-option ballot | 15.7 KiB |
| Encrypt + prove a 16-option ballot (voter device, one core) | 69 ms |
| Verify a 16-option ballot (server, one core) | 107 ms |
| Record size of a 16-option ballot | 56.2 KiB |
| Blind-sign one credential (RSA-3072) | 2.9 ms |
| Homomorphic aggregation, per ballot-option | 37 µs |
| One trustee's decryption share with proof | 3 ms |
| Recover a count of up to 60 lakh (baby-step giant-step) | 77 ms |
| Merkle append, per entry | 12 µs |
| Sequencer ingest, one shard, group commit with fsync | 1,207 ballots/s |
