What it guarantees

PropertyHow
Only eligible voters, once eachAuthenticated, blind-signed credential bound to one constituency; one ballot per credential
Secret ballot3-of-5 threshold encryption; individual ballots are never decrypted
Only valid ballots countZero-knowledge proofs: exactly one selection, NOTA included
Voters can check their ballotTracking code with Merkle inclusion proof; challenge to catch a lying device
Anyone can check the resultAppend-only signed record, homomorphic tally, proven decryption, a verifier that shares no code with the election software

What it does not solve

Coercion and vote-buying, a compromised voter device, denial of service, and credential minting by a dishonest eligibility authority. These are documented as open risks in the threat model — and are why this project does not recommend remote online voting for binding public elections.
